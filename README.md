Habit Tracker (v1.1)

A cross-platform habit-tracking application for Android and Windows.

📖 The Origin Story: Why I Built This

This project started at the beginning of the year with a simple goal: I wanted to build a habit of coding. What better way to build a coding habit than by creating a habit tracker?

Initially, this was a 7-day coding challenge. By the end of that first week, the core functionality was already there. Even with a simple UI, it worked. Since then, I have heavily upgraded the user interface, expanded the logic, and fully packaged the application for both PC (Windows) and Android devices.

✨ Features

Cross-Platform: Run it on your Android phone or your Windows PC.

Flexible UI & Theming:

Modes: Auto (adapts to your device's system settings), Dark, and Light mode.

Themes: Beautiful color schemes based on traditional UI color pairings.

Smart Habit Tracking & Streaks:

Track individual habits with precision.

Daily & Weekly Targets: Tell the app how many days a week you want to complete a habit (up to 7).

Streak Logic: Build up your streak! If you miss a daily habit or fail to meet your weekly target, the streak automatically resets to keep you accountable.

Reward System: Set custom rewards to keep yourself motivated. You can assign rewards for completing a specific streak or for completing all your streaks.

🚀 Installation Instructions

Note: For more details, you can also reference the HOW_TO_INSTALL.txt file included in the release.

Windows (Laptop / PC)

Note: The old published build crashed instantly due to a Microsoft.UI.Xaml.dll issue. This is now fixed by shipping the Windows App SDK with the app (self-contained unpackaged).

Download and extract/copy the ENTIRE folder: Releases\Windows

Double-click "Start Habit Tracker.bat"
(Alternatively, run Habit tracker.exe — but ensure you keep all DLLs in the same folder beside it).

Android (Phone)

Note: Rebuilt as a fresh signed APK (version 2).

Important: Uninstall any previous versions of Habit Tracker on your phone first if the installation fails.

Copy the installation file to your phone: Releases\Android\com.companyname.habittracker-Signed.apk

Open the APK file on your device and tap Install.

When prompted, tap Allow notifications for the app to work flawlessly.
